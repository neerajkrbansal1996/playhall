# Asset licences

Art, audio, fonts, 3D models and textures. **Every asset must be CC0 or commercially
licensed, and logged here in the same PR that commits it.** An asset with no row is a
release blocker.

Required for each entry: what it is, where it came from, the exact licence, a link to
the licence text, whether attribution is required, and where the attribution is shown.
